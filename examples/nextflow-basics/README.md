# Executable Nextflow basics

Run these examples in numerical order from this directory:

```bash
cd examples/nextflow-basics
nextflow run 01-hello.nf --name Ada
nextflow run 02-one-file.nf
nextflow run 03-many-samples.nf
nextflow run 04-paired-reads.nf
nextflow run 05-two-step-workflow.nf
```

The files are deliberately tiny and use only standard shell commands. They are teaching fixtures, not biological analyses.
